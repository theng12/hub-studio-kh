# Studio Hub

An internal Mac application for the owner's new Apple Silicon fleet nodes. One app contains Audio, Transcription, Image, Music, Video and Chat functions, with Hub managing jobs, node connections, models and shared machine capacity. Existing Pinokio installations remain separate.

The owner selected SwiftUI/AppKit with WKWebView to reuse the existing Studio interfaces, a menu-bar presence, optional start at login, external model storage and bundled runtimes. The first usable functions build on the tested Voice worker; unavailable engines must be described honestly. Simplicity means copying an app and choosing models, with no terminal or dependency installation for normal use.

Use native macOS controls around the existing Studio UI. This extends the established interface; it is not a visual redesign. Preserve accessible labels, keyboard navigation, readable failure states and current generation safeguards. No paid Apple membership is available; local development continues, distribution qualification remains separate.
