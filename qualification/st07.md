# ST-07 output-storage implementation receipt

Source-backed preparation used the ST-02 Hub settings owner, delivery receipt route,
broker finalization hook, existing Hub SQLite ledger and Voice generation persistence.
The policy uses no new dependency or process: `components/hub/output_storage.py` adds
two tables to the existing `hub.db`; the Hub process performs the configurable
five-minute sweep.

The private descriptor is the trust boundary for managed roots. A result path is indexed
only when it is a regular non-symlink below a supplied root and its reported size/checksum
matches the file. The index persists original `generated_at`; copying a file cannot reset
retention. Physical inode/device pairs are counted once across Image, Voice and Subtitle.

Cleanup first removes acknowledged, unleased groups older than the age boundary, then
oldest acknowledged groups until the byte budget is met. Unacknowledged, active/uncertain,
reader-leased and transfer-leased groups remain protected. A protected over-budget device
returns `OUTPUT_STORAGE_BLOCKED` with its actual indexed and free-space values. Missing
roots, inaccessible paths, symlinks and partial deletion are reconciled conservatively.

The editable `minimum_free_bytes` floor defaults to 1,000,000,000 bytes and accepts zero
to disable that independent admission check. Hub admission measures descriptor-supplied
managed roots even before an output is indexed. A receipt retry repairs a failed output-index
acknowledgement without recontacting the worker; worker ACK responses must explicitly return
`{"ok": true}`. A failed index registration records `output_storage_error` while preserving
the completed item, so a completed worker inference is never retried for housekeeping.

The sweep and lease acquisition share one in-process lock. It rechecks device/inode,
size, mtime and checksum immediately before unlinking; a replacement turns uncertain
and remains intact. Hard-link ctime changes do not invalidate a matching remaining link.
Hub startup clears process-local reader/transfer leases left by a crashed prior process.
An unavailable managed root is recoverable only after every original indexed identity and
checksum returns; other uncertain states remain protected. Preview reads an existing index
without creating a database, reconciling it, or deleting; database errors remain errors.
Delivery holds a transfer lease while it records the worker receipt and Hub acknowledgement.
