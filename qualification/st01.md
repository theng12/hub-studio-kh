## Real file and transport proof

[Whisper import receipt](st01-model-import.json): nine files, **1,618,590,987 bytes**,
all verified against captured SHA-256 values. Selected existing isolated pilot-cache
assets were assembled using read-only hardlinks, then imported into an independent
package. Moving the library to a path with spaces retained valid registration;
refresh did not copy the weights again. No installed cache symlinks remain. Original
source sizes and modification times were unchanged. This ran in 6.29 seconds.
The imported companion folder also passed an offline `WhisperTokenizer` load and
text encode/decode round trip, matching the adopted narrow tokenizer adapter.

[HTTPS receipt](st01-https-smoke.json): three real, pinned processor files totaling
89,500 bytes downloaded and verified in 1.8 seconds. No model weights were downloaded.
Fixture tests cover GitHub-style mirrors, redirect validation and interrupted transfers.
The full catalog describes 24,494,855,896 expected bytes; this phase does not claim
all those model bytes were present or verified locally.

The retained Whisper artifact is under the implementation worktree's
`.build/ST-01 Moved Model Library/whisper-turbo/a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb`.
Its source is the pre-existing isolated `.build/pilot-models/hub` cache in the project
root, not an installed fleet machine's cache.
