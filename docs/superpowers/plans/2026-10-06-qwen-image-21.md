# Qwen Image 2.1 Implementation Plan

> For agentic workers: use subagent-driven-development task by task. Workers do not commit, publish, deploy, or delegate. Root owns integration and release.

**Goal:** Add Qwen Image 2.1 to ordinary Story/Gateway/Hub model discovery, stock it on all four SSDs, and extend the existing SSD qualification workflow for physical 24 GB and bounded 16 GB tests.

**Architecture:** Retain one Image worker, one FIFO, and the Hub's physical-machine lease. The verified ddalcu q4 pack runs via a pinned mlx-serve leaf owned by that worker. A separately identified mflux full-q4 pack supplies the bounded low-RAM candidate; do not silently substitute checkpoints beneath one model ID. Normal language/use selection remains the owner's choice. No English-only product restriction or default-model replacement.

**Tech Stack:** Existing Python Image worker/mflux 0.20, mlx-serve 26.10.1 arm64, native Swift shell, existing model library and SSD kit scripts.

**Spec/evidence:** `_orchestra/audit-20261006/qwen-image-21/RESULTS.md` (outside repo). Owner approved integration/SSD preparation and will run physical SSD tests. 32 GiB standalone English evidence exists; 24/16 GiB are compatibility targets until physical receipts arrive. Product admission remains conservative pending qualification.

## Review focus

- Worker crash/parent loss must not orphan native leaf or its memory; cancellation must terminate/kill it and discard cancelled late results.
- Native leaf inherits no fleet/HF credentials or loader overrides, binds only ephemeral loopback, authenticates local requests, and accepts only bounded image responses.
- Qwen must release resident mflux first; queued Qwen and Qwen↔mflux work serialize under the existing lock and broker lease.
- Missing binary, bad revision/files, child/preflight failure, malformed image/shape, and deadline produce truthful readiness/terminal states without delivering a false success.
- Kits select models by qualified RAM and Lite allowlist; qualification candidates remain available to the dedicated tests without broadening ordinary 8/16/24 production admission.
