# ST-07 — Per-device generated-output cleanup

Status: READY · Owner/session: Unassigned · Prerequisites: ST-02

## Deliverable

One editable size/age policy across Image, Voice and Subtitle on each device.

## Files and ownership

Hub output/settings modules selected in ST-02; existing worker receipt/deletion APIs; new tests/test_output_policy.py. No extra daemon.

Read [design](../standalone-plan.md), [execution rules](../implementation-plan.md) and [board](BOARD.md). New paths are intended implementation targets.

## Checkpoints

- [ ] ST-07.1: Persist device-scoped defaults: 50,000,000,000 bytes, 30 days, cleanup enabled and proposed editable five-minute cadence (not inherited source behavior). Admission checks remain authoritative between sweeps.
- [ ] ST-07.2: Index finalized output groups with immutable generated_at, physical bytes, paths and receipt state; include derivatives and avoid double-counting references.
- [ ] ST-07.3: Expire eligible old groups, then oldest eligible groups while usage reaches budget. File copying must not reset age.
- [ ] ST-07.4: Protect active/uncertain work, readers, transfers and unacknowledged results; exclude models, originals, voice references, credentials, evidence and explicit exported copies outside the managed root. Changing the managed output folder keeps generated files indexed/countable/reclaimable.
- [ ] ST-07.5: Check free disk space independently. If protected outputs prevent compliance, retain them and return OUTPUT_STORAGE_BLOCKED with honest usage.
- [ ] ST-07.6: Apply authenticated per-device changes with preview/durable acknowledgement. Reconcile partial deletion, restart, missing SSD and permission errors safely.
- [ ] Independent review resolved; verified integration and handoff recorded.

## Required proof

Temporary fixtures and controlled-clock tests for exact age/byte boundaries, either limit, combined studios, changed defaults, protected receipts, symlink escape, duplicate references, changed managed root versus explicit external export, and partial deletion. Never test cleanup on user output files.
