## Checkpoints

- [ ] ST-01.1: Inventory exact Hub/Image/Voice source commits and official checks. Reconcile declared versus resolved mlx-audio revisions; prove compatible locked runtimes without forcing one environment.
- [ ] ST-01.2: Pin all ten models and companions. Capture missing revisions from official metadata without polling existing downloads. Use available selected assets or separately authorized acquisition.
- [ ] ST-01.3: Define immutable manifests, atomic import and readiness. Reject missing/unreadable shards, broken symlinks, bad hashes and absent processors; interrupted import must preserve the working revision.
- [ ] ST-01.IMPORT: Implement equivalent GitHub/original-host download and copied-folder import paths. Validate complete companion assets, recognize supported layouts using known manifests, refresh/register folders already inside the selected library in place (stage/copy external imports into it unless the owner first selects that SSD library root), reject LFS pointers and incomplete copies, and avoid redundant downloads/copies. Portable packages must not depend on cache symlinks on another Mac. Keep executable dependencies in the qualified app runtime; report runtime mismatch explicitly.
- [ ] ST-01.4: Record editable supported model defaults and actual RAM evidence. Base/Small/Turbo are recommended Subtitle defaults; leave unqualified combinations explicit.
- [ ] ST-01.5: Trace callers/imports before pruning inherited dependencies; retain unresolved current dependencies until requested inference/quality checks prove removal safe.
- [ ] ST-01.6: Publish the small runtime contract with ST-02's integration owner. Record build-side input archives, hashes and redistribution notices.
- [ ] ST-01.OS: Preserve original-M1/macOS-14 compatibility as the qualification baseline. Audit actual native binary floors and Metal/runtime requirements for each selected model and precision. Pin older-OS-compatible artifacts explicitly; do not confuse SDK version with runtime floor. Record exact point-release requirements and unresolved inference tests; no unproven pre-Sonoma or CPU fallback promise.
- [ ] Independent review resolved; verified integration and handoff recorded.
