# ST-20 — the lane execution contract (Gateway Studio's ask)

**Status:** DONE in 0.6.61, 2026-09-25. The four behavioural asks (1, 2, 4 and the measured
limits) are delivered and verified; video (3) stays a forward declaration until a video worker
ships. What remains open is listed at the end.

## Why

Gateway Studio — the sibling project that schedules work onto Hub nodes — asked for this by name in
`_handoffs/2026-09-25-studio-hub-lane-contract-prompt.md` (committed there as `1ad796e`). Their
framing is the whole justification:

> Discovery is already solved — the gateway now reads the modality the Hub states, so a model on a
> new engine arrives instead of vanishing. Dispatch is not, and that's the ask.

A scheduler can learn *that* a lane exists from a modality string. It cannot learn what to send,
what comes back, which states are terminal, or what a cancel means. Today it guesses those from an
engine table, and a guess is what produced the silent model drop the modality field just removed.
With a published contract, a new lane is a data change on the Hub side and **no gateway release**.

The shape is specified in `docs/lane-execution-contract.md`. That file is the contract; this card is
the work.

## What the contract states, in one place

- `operation` — the canonical token from `capabilities.OPERATION_BY_MODALITY`, so it joins to the
  Hub's namespace. (Music's worker label is `music.text_to_music`; the canonical token is
  `music.generation`, and the Hub keeps the worker's wording in `hub_reported_operation`.)
- `parameters` — the **asked-for** surface with `type`, `required`, and the bound that is actually
  enforced, built from the model's own limits. A parameter the lane ignores or refuses is **not**
  listed.
- `artifact` — `modality`, `media_type`, `extension`, `per_item`.
- `states` — `accepted` / `active` / `terminal`, plus `uncertain` and the explicit
  `uncertain_is_terminal: false`. `uncertain` is held for an operator decision; a scheduler that
  treats it as finished either loses an artifact or double-charges a machine.
- `cancel` — the request shape and, in `semantics`, what it does **not** promise.
- `runtime_seconds` — what one item costs, **only where measured**, as a list of rows so a lane
  whose cost depends on a request parameter publishes the same shape as one whose cost does not.
  Absent means unmeasured; a guessed runtime is how a scheduler sets a deadline that fails on use.
- `deadline_seconds` — added by the **Hub**, not the worker: the 900 s is the Hub's own peer-proxy
  timeout (`standalone.py:1867`), one constant owned by the party that enforces it.

## Measured model limits (ask 4)

`mlx-community/Qwen3.5-9B-4bit` publishes `text_config.max_position_embeddings = 262144` in its own
`config.json` **[M]**, which `llm_engine.py` already reads. The checkpoint ships **no**
`generation_config.json`, so `max_output_tokens` is the worker's own `4096`
(`FALLBACK_MAX_OUTPUT_TOKENS`) and is published as a worker default, not as the model's number.
Gateway was publishing a curated flat `1,000,000 / 128,000`; the fix is not a better curated number
but provenance beside every value and **no value at all** where nothing states one.

Related defect fixed in the same pass: `model-manifests/qwen3-5-9b-4bit.json` pointed
`defaults.parameters_source` at `model/generation_config.json`, a file neither the package nor the
publisher ships — a dead pointer to the very file the limits would have come from.

## Evidence

- `tests/test_worker_version_reporting.py` — no worker may answer a string literal for
  `app_version`; the shared reader returns a version, a labelled development version, or `unknown`.
- `tests/test_music_lane_contract.py` — every catalog model publishes a contract from its own
  limits; a lane that discards a control does not offer it; every published runtime traces to a
  stored probe file.
- `tests/test_image_bundle.py::ImageLaneContractTests` — the same properties for Image, plus
  "an ignored control is published as ignored" (Z-Image-Turbo 4-bit runs without CFG).
- `packaging/stage_voice.py::shared_components_modules` — shared modules are staged by discovery,
  so `components/app_version.py` cannot be silently left out of a bundle.

## Open after 0.6.61

1. **Pocket TTS 4-bit (MLX 4-bit) cannot reach its eight preset voices.** It ships them
   (`pocket-tts-preset-voices`: `alba`, `azelma`, `cosette`, `eponine`, `fantine`, `javert`, `jean`,
   `marius`) and also declares cloning, so it lands in one tab only. Needs a per-model
   `preset_speakers` roster derived from that package's own file names, a published `modes` list,
   and the app offering a model in each mode it publishes. This is the one shipped feature known to
   be unreachable, and it is the same shape as the bug this workstream started from.
2. **An unannotated studio row still falls back to capability tokens** for chat detection. The
   durable fix is that every studio row carries the Hub's own `hub_modality`, which it already
   adds — the fallback should be deleted once no producer needs it.
3. **Video.** `docs/lane-execution-contract.md` carries the forward declaration and the one route
   the Hub has (text-to-video). No contract is published until a worker exists to enforce it.
