# Open work — hub-studio-kh

Open tasks and known defects for this repository only; updated in the same commit whenever work starts, changes, or closes. Shipped work lives in `CHANGELOG.md` and `docs/receipts/`.

- [ ] **The gate runs 15 of 324 test modules** — the `suites` step lists its modules by hand while `tests/` holds 324 top-level `test_*.py` files, so a regression outside those 15 passes the gate unseen. **Next:** replace the hand list with a discovered sweep (or an explicit, justified exclusion list), and prove a deliberately broken unlisted module fails the gate.
- [ ] **Whole-fleet and long-run idle footprint are unmeasured** — 0.6.262 measured 125 MB after 600 s idle, 1 MB lower than at start, but the owner's ceiling names three states and the other two have no number. **Next:** measure during a whole-kit run and after a long run of model transfers or jobs, and record both on the next receipt.
- [ ] **Stray release tag `wire-0.5.0` in this repo** — it names `460586a4` ("hub: kit retire names from data") and carries another app's DMG name, so a person or a script looking for Wire's release on this repo finds a tag pointing at Hub's commit. **Next:** retire the tag recoverably and confirm nothing references it, or document why it must stay.
- [ ] **`capture_model_manifests.py --write` cannot complete** — a different package's pinned revision no longer resolves upstream (HTTP 404 on the publisher's side), so the catalogue cannot be regenerated in full. Recorded, not worked around. **Next:** re-pin that manifest to a revision that resolves, or drop the package from the catalogue with a changelog line.
- [ ] **Replace-and-relaunch of Hub's own updater is unproven** — hold, download, safe abort and resume are proven live; the actual swap has never happened on a built Hub. **Next:** the first real update served to an installed 0.6.261 or later is the proof — capture the version readback before and after.
- [ ] **A model that fits but is not installed can read as "no Mac able to run it"** — Hub now publishes `needs_gb`/`needs_source` for every model, but the consumer side (Gateway) still collapses that into an unreachable verdict. **Next:** Gateway's 0.2.309 RAM-fit gate closes this; Hub's part is to keep the field truthful and measured.
- [ ] **A failed row for work whose output is not a file never resolves** — recorded from Production; the same shape can leave a model-import or preset run showing as failed with no way to settle it. **Next:** reproduce with a non-file output and make the terminal state reachable.
